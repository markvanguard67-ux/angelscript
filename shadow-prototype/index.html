Pixel-art dynamic shadow generator

A JavaScript prototype of the shadow technique from “Graveyard Keeper: how the graphics effects are made” — shadow sprites rotating around a pivot, max 4 per object (1 sun + 3 nearest lights), the rotation parameter smuggled through a vertex colour channel, plus the surrounding pipeline: ambient light, LUT colour correction, normal maps, 3D light distribution, altitude fog.

how it maps to the article

  1. Sprites rotating around a point. Each caster owns a pivot at its feet; a black shadow sprite is rotated around it. Skew is available and defaults to 0 — the author tried it and dropped it.
  2. 4 shadows max. Slot 0 is the sun (the moon at night), slots 1–3 the three nearest dynamic lights, re-selected every frame.
  3. Rotation in the vertex shader, parameter in a colour channel. shadowVertexStage() transforms 4 corners from a packed RGBA8: R = angle (8-bit ⇒ ~1.4° steps, shown live), G = length, B = intensity, A = width. No transform is ever touched.
  4. Vertical distortion. The ground plane is squashed (squashY), so a rotation also reads as a distortion — push squash to 1.0 to see the pure rotation.
  5. Per-object shadow sprites. ~10 universal blobs (thin / thick / oval / tree / human / fence …). The fence run shows the known weak spot for objects stretched along one axis.
  6. Nearest-3 query in Update(). Timed in the HUD; toggle the spatial grid to see what the Jobs-system version would buy you.
